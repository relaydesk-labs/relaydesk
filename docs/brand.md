# RelayDesk Brand

## Direction

RelayDesk should feel like a work hub, not a helpdesk queue.

The visual identity uses a simple `R` mark with a desk/workflow baseline:

- `R`: RelayDesk product name and routing intelligence
- inner cut: request flow moving from ask to resolution
- bottom line: shared work surface for human owners and agent contributors

## Color

```text
Primary: #2563EB
Primary Dark: #1D4ED8
Primary Soft: #EFF6FF
Text: #1F2937
Muted: #6B7280
Line: #E5E7EB
```

## Usage

- Use the full wordmark in app navigation.
- Use the square mark for favicon and compact contexts.
- Do not use company-specific logos in the core repository.
